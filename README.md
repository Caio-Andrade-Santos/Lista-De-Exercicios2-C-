# Lista de Exercícios em C++

Este repositório contém uma coleção de exercícios desenvolvidos em C++, abordando conceitos fundamentais de programação, manipulação de strings, entrada e saída de arquivos e controle de fluxo.

## Autores

* Caio Andrade
* Alexandre Zampieri

---

## Exercícios

### Exercício 1 – Animação de Palavra no Console

Programa que recebe uma palavra e a exibe com um efeito de movimentação vertical no console, utilizando funções como `gotoxy` e `Sleep` para simular uma animação.

---

### Exercício 2 – Verificação de Palíndromo

Recebe uma palavra ou frase e verifica se ela é um palíndromo.
O programa remove os espaços e compara a string original com sua versão invertida.

---

### Exercício 3 – Formato de Lista Telefônica

Lê nomes a partir de um arquivo `.txt` e os transforma para o formato de lista telefônica.

Exemplo:

```text
José Antonio Santos Silva
Silva, José Antonio Santos
```

Os resultados são gravados em um arquivo de saída.

---

### Exercício 4 – Formato de Citação Bibliográfica

A partir de uma lista de nomes em arquivo `.txt`, converte os nomes para o formato de citação bibliográfica.

Exemplo:

```text
José Antonio Santos Silva
SILVA, José A. S.
```

O programa realiza a separação do sobrenome, transformação para letras maiúsculas e geração das iniciais dos demais nomes.

---

## Tecnologias Utilizadas

* Linguagem C++
* Bibliotecas padrão (`iostream`, `fstream`, `algorithm`, `cctype`)
* Manipulação de arquivos (`ifstream`, `ofstream`)
* Manipulação de strings

---

## Estrutura

* `nomes.txt` → entrada para o exercício 3
* `lista1.txt` → saída do exercício 3
* `nomes2.txt` → entrada para o exercício 4
* `lista2.txt` → saída do exercício 4

Praticar conceitos essenciais de programação em C++, incluindo estruturas de repetição, manipulação de strings, leitura e escrita em arquivos e lógica de algoritmos.
